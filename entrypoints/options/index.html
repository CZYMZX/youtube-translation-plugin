降级顺序 从上到下逐级尝试。拖动 ⠿ 或点行尾的 ↑ ↓ 调整；标「未排序」的厂牌还没写进顺序，调一次就加入。

未设置顺序时，失败会直接降级到 Google 免费翻译。

ASR 纠错授权 常规：按上下文修正明显的同音误转；严格：仅在上下文能确证时纠正，不确定保留原文。 两种模式的 token 消耗几乎无差别。

复杂配置

翻译场景

场景决定注入给模型的身份与语气。左侧选场景只是「查看」，右侧逐层展开它实际注入的 system prompt；要换用某个场景，点右侧的「使用此场景」。

翻译场景 0
文件格式规范（JSON）· 点开查看

必须是 UTF-8 编码的 JSON 对象（单文件 ≤ 1 MB）。校验不通过会逐条列出原因，不合格的文件不会进库。

字段必填限制说明
name✅1~40 字场景名称，列表展示
prompt✅20~4000 字场景提示词，作为 system prompt 的场景段注入
description否字符串场景说明
hint否字符串示例（如适合的视频类型）
version否数字建议 1

不允许未知字段（防止拼写错误被静默忽略）。

可直接复制的完整示例：

{
  "version": 1,
  "name": "科普视频",
  "description": "科学解说 / 教育内容",
  "hint": "例：TED-Ed、物理讲解",
  "prompt": "你是一位科普视频字幕译者。要求：术语准确并使用业界通用译名；逻辑连接词清晰；保留公式、单位与数字原样；不添加原文没有的信息；语气客观、面向大众读者。"
}

常见错误（报错原文 → 怎么改）：

现象原因处理
缺少字段 prompt（场景提示词）顶层只有 name，忘了写 prompt补一个 20~4000 字的提示词
prompt 少于 20 字，无法有效指导翻译只写了一句「翻译得好一点」按 5 个要素补全：角色、受众语气、术语策略、格式数字、禁止事项
prompt 超过 4000 字把整篇文档 / 整段聊天记录贴进来了只保留「这类视频该怎么译」的行为约束
文件内容不是 JSON 对象交的是数组、纯文本、空文件顶层必须是 { … }，不是 [ … ]
存在未知字段：promt, instruction键名拼错，或用文档里的说法当键名只留 version / name / description / hint / prompt 五个字段
version 写成了 2当前只认 1，但不会因此被拒（校验不看这个字段的值）改成 1；非 1 也没有任何升级含义

断句引擎

断句决定「一句话」的边界，也是翻译与显示的最小单位。数值越小切得越碎。

语言策略 自动会按假名 / 谚文 / 汉字 / 拉丁字符比例判断，通常无需手动指定。
停顿切分阈值 静音超过该值视为换气，倾向断句。真人语速快时建议调低。
单句最大字数 中日韩按字计。超出即强制切断，优先落在标点或助词边界。
单句最大时长 防止一句字幕停留过久，观众读完还在屏上。
单句最大词数 仅对英语等拉丁语言生效，与字数上限互不影响。
智能标点修补 给无标点的 ASR 文本补首字母大写与句末标点，译文更易读。
短碎片合并 把「诶？」这类无标点碎片并进相邻句，减少一闪而过的断行。

字幕样式

改动即时反映在下方预览；预览用假数据渲染，不受当前视频影响。

00:42

今日はね、ちょっとだけ遅くなっちゃった。

今天呢，稍微拖晚了一点点。

显示方式 双语对照适合学习，纯译文更适合追剧。
上下顺序 译文在上更贴近阅读习惯，原文在上更便于对照听辨。
字号 全屏观看时 24–28px 通常最舒服。
背景不透明度 0 为完全透明，过高会挡住画面。
垂直位置 数值越大越靠画面底部；遮挡进度条时可上调。
配色 背景、原文、译文三种颜色。深色背景下译文用高饱和色更清晰。

同步与缓存

对齐音画、处理原生字幕重叠，以及清理本地缓存。

时间轴偏移 字幕整体提前或延后。人声比字幕晚出现时调负值。
隐藏原生自动字幕 避免 YouTube 自带字幕与本插件浮层上下重叠。
AI 精翻字幕保留时长 保留期间重新打开视频会直接载入本地精翻字幕，不再重翻。 永久保留不会自动清理，需要时可用下方「清空 AI 精翻缓存」手动释放。
视频续播时自动继续精翻 检测到上次只翻了一半时：手动＝只提示、等你点按钮；自动＝直接接着翻。 两种模式都只翻缺失部分，并带上文两句保持语境。
AI 精翻缓存 正在统计本地 AI 精翻字幕… 清空后重新打开视频需要重新精翻，已缓存的普通机翻译文不受影响。
翻译缓存 已缓存的句子会直接复用，不再请求模型。
恢复出厂设置 重置全部设置项，术语库与自定义场景包会保留。

用 AI 生成模板

整段复制，粘到你常用的 AI 里；第一行「# 需求：」后面写你想要什么，让它直接产出可导入的 JSON。

第一行是留给你的空位；输出必须能被 JSON.parse 直接解析，导入失败会逐条告诉你哪一项不合格。
