点卡片即切换；「上传」可导入自定义场景包。
翻译场景上传规范

JSON 对象，必填 name（≤40 字）与 prompt（20~4000 字）：

{
  "version": 1,
  "name": "科普视频",
  "description": "科学解说 / 教育内容",
  "hint": "例：TED-Ed、物理讲解",
  "prompt": "你是一位科普字幕译者。要求：术语准确、逻辑清晰、保留公式与单位……"
}

prompt 会作为 system prompt 的场景段注入；请写明受众、语气、术语处理与禁止事项。上传后立即出现在场景列表，选中即生效。

术语库上传规范

JSON 对象，必填 name 与非空 entries 数组（≤2000 条）：

{
  "version": 1,
  "name": "MC 游戏术语库",
  "description": "Minecraft 方块 / 生物 / 机制",
  "entries": [
    { "ja": "クリーパー", "zh": "苦力怕", "en": "Creeper", "category": "term",
      "source": "https://zh.minecraft.wiki/", "sourceType": "wiki" }
  ]
}

每条必填 ja（日文原词）与 zh（中文译名）；category 可选 talent/group/game/song/term，缺省按 term 处理。翻译时只注入本批文本命中的术语。
