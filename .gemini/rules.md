# 油管翻译插件 - 工作区跨会话统一协同开发规范 (Workspace Rules)

> [!IMPORTANT]
> **本项目当前绝对基准版本：v0.4.0**  
> 所有参与本项目的 Antigravity 会话（包括历史老会话、并行会话与新会话），必须以本规范为绝对准则，**严禁将插件代码倒退回 v1.0.x 旧版本结构**！

## 1. 核心设计与视觉统一规范（严禁回退）

### 1.1 纯净黑白毛玻璃视觉体系 (Monochrome Glassmorphism)
- **全局色彩原则**：除**字幕展示框**与**译文字体颜色**允许用户在设置中自定义彩色外，所有扩展 Popup 界面、播放器内嵌快捷面板（QuickPanel）、全文字幕抽屉（Transcript Drawer）以及悬浮弹窗，**严格保持黑白深邃磨砂质感**。
- **背景与边框**：
  - 容器背景统一使用 `rgba(14, 15, 18, 0.88)` ~ `rgba(18, 18, 22, 0.92)` 配合双层 `backdrop-filter: blur(16px)`。
  - 边框统一使用 `1px solid rgba(255, 255, 255, 0.12 ~ 0.18)` 与顶部立体微透高光 `inset 0 1px 0 rgba(255, 255, 255, 0.12 ~ 0.15)`。
  - **严禁行为**：严禁在后续迭代中引入彩色渐变底色（如粉紫色渐变、蓝绿大块渐变背景）。

### 1.2 矢量图标体系与状态微动效规范 (ByteDance IconPark Suite)
- **统一矢量规范**：所有图标**必须且仅能使用** `utils/icons.ts` 导出的 **ByteDance IconPark 官方单色矢量 SVG**（标准属性：`viewBox="0 0 48 48"`，`fill="none"`，`stroke="currentColor"`，`stroke-width="4"`，`stroke-linecap="round"`，`stroke-linejoin="round"`）。
- **状态栏与状态图标**：
  - 检测中：使用 `ICON_HOURGLASS` 矢量沙漏，挂载专属物理旋转动画 `.hourglass-flip-anim`（顺时针旋转 180° 停顿沙流，再顺时针旋转 180° 停顿沙流，无缝循环）；
  - 字幕已就绪：使用 `ICON_CHECK` 纯白单色矢量对勾；
  - 警告/未检测到字幕：使用 `ICON_ALERT` 纯白单色矢量三角形叹号；
  - 状态提示文字统一使用柔和纯正的 `#e4e4e7` / `#ffffff`，重试按钮使用纯白下划线微光，**严禁使用亮蓝色（#38bdf8）破坏黑白毛玻璃一致性**。
- **严禁行为**：**严禁直接在 DOM 或按钮中插入系统原生彩色 Emoji**（如 ⏱️、⚙️、📖、💡、✨、📑、⏳、⚠️ 等）。所有状态、操作与徽标均由矢量 SVG 承载。

## 2. 关键业务组件与交互标准规范

### 2.1 扩展弹窗 (Popup) 规范
- **翻译服务引擎详细参数手风琴折叠**：
  - 当用户选择大模型服务（DeepSeek、OpenAI、Gemini）时，`API Key`、`Base URL`、`模型选择` 与 `测试延迟` 模块**必须默认收拢在 `#ai-config-section` 折叠卡片内**；
  - 折叠卡片头部必须动态展示状态 Badge（`已就绪` / `未配置`）与当前模型名称（如 `当前模型: gemini-3.5-flash-lite`）；
  - 严禁将其恢复为默认铺满界面的大表单展开卡片。
- **标签页切换防抖与稳定槽位（绝对消除左右晃动）**：
  - `html` 与 `body` 必须强制配置 `scrollbar-gutter: stable;`；
  - `body` 必须配置 `overflow-y: scroll;`；
  - 滚动条必须统一定制为 5px 宽的半透明极简轨道与滑块，无论处于哪个 Tab（包括内容较短的「断句引擎」），右侧槽位宽度绝对恒定，**严禁产生由于滚动条有无导致的左右位移**。

### 2.2 剧本全文抽屉 (Transcript Drawer) 规范
- **禁止调用原生 Element.scrollIntoView() 冒泡滚动**：
  - 抽屉内滚动定位当前句必须通过 `drawerListEl.scrollTo(...)` 容器纯内部滚动计算，**严禁使用原生 `scrollIntoView()`**，防止事件冒泡导致 YouTube 视频及整个页面向左平移弹动；
  - 宿主容器 `#yt-sub-translator-host` 必须常驻 `overflow: hidden;`，物理级剪裁抽屉滑出轨迹。
- **「5s回到当前句」浮动弹窗**：
  - 用户在抽屉列表中手动上下滚动翻阅后，底部浮现出胶囊药丸弹窗；
  - 倒计时基准时间为 **5 秒**（`5s` → `4s` → `3s` → `2s` → `1s` → 自动平滑滚动回当前句并隐藏）；
  - 弹窗采用纯净黑白毛玻璃底色，图标严格使用 `ICON_STOPWATCH` 矢量秒表图标；
  - 点击按钮立即无延迟瞬时归位。
- **当前句高亮选择框动态变色**：
  - 抽屉中当前播放句的激活样式（`.drawer-item.active, .drawer-item.current`）**必须通过 CSS 变量动态绑定到用户设定的当前译文颜色 (`transColor`)**；
  - 边框线色、微光背景与呼吸发光效果必须随译文颜色动态改变，**严禁写死固定天蓝色**。
- **抽屉细滚动条**：
  - `.drawer-sentences-list` 必须使用 5px 细滚动条，严禁露出 Windows 默认原生白色粗滚动条。

### 2.3 播放器快捷面板 (QuickPanel) 规范
- **稳定高度与向下展开（严禁展开时整体上移）**：
  - 面板外框高度必须保持稳定（`height: min(470px, calc(100% - 68px))`），禁止由内容自适应撑大导致底端定位向上推挤整个面板；
  - 折叠项（双语排版模式、时间轴微调、场景、推理深度）必须采用 **CSS Grid `grid-template-rows: 0fr -> 1fr` 弹性向下平滑展开**，被点击选项自身屏幕坐标保持不动；
  - 展开后超出弹窗范围由内部垂直滚动条承载，滚动条风格严格使用 5px 细半透明毛玻璃滚动条。
- **平滑选项切换器 (Smooth Option Switcher)**：
  - 双语排版模式、翻译场景切换、推理深度切换等均采用弹性物理滑块动效；
  - 必须保持 `box-sizing: border-box`，防止内边距挤压导致内容超出底框。

## 3. 会话构建与发布规范
- 构建命令统一为：`npm run build`（按序生成 `.output/edge-mv3` 与 `.output/chrome-mv3`，以 Edge 优先）。
- 每次改动必须执行 `npx tsc --noEmit` 确保 0 报错。
- 版本号严格遵循 `0.1.0`（或后续版本递增），禁止降级为 `1.0.x`。
