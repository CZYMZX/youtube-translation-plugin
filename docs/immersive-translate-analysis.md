# 沉浸式翻译 (Immersive Translate) 字幕翻译核心技术深度解析与留档

> **参考仓库与产品**：[immersive-translate/immersive-translate](https://github.com/immersive-translate/immersive-translate)  
> **留档主题**：视频字幕翻译（以 YouTube 为代表）的核心架构、断句算法、渲染机制与工程化设计  
> **留档时间**：2026-10-27  

---

## 一、 产品定位与核心价值

沉浸式翻译（Immersive Translate）是国际公认的顶级双语网页与视频翻译扩展。其在 **视频双语字幕（Video Subtitles）** 领域的核心设计理念可总结为：

1. **极度尊重原视频体验**：不破坏视频播放器的原生交互，以 Shadow DOM 无缝覆盖，视觉风格高度契合原生。
2. **解决机器生成字幕（ASR）的碎片化**：通过启发式算法将 YouTube 自动语音识别的碎片词重构成人类自然句。
3. **上下文感知的高品质翻译**：借助滑动窗口批量送翻，维持多句指代与口语语境。
4. **灵活多样的双语排版**：支持上译下原、上原下译、仅译文、仅原文，满足语言学习、娱乐看片、技术研习等多重诉求。

## 三、 关键技术细节拆解

### 1. YouTube 字幕协议与 `json3` 格式
YouTube `api/timedtext` 服务默认输出的 `json3` 具有极高的时序精度：
```json
{
  "events": [
    {
      "tStartMs": 1000,
      "dDurationMs": 2800,
      "segs": [
        { "utf8": "Hello, " },
        { "utf8": "this is a " },
        { "utf8": "live demo." }
      ]
    }
  ]
}
```
- **核心要点**：
  - `tStartMs` 与 `dDurationMs` 提供了绝对时间戳；
  - `segs` 内部的词片往往不带标点，沉浸式翻译需提取所有 token 的 `tStartMs`，在相邻 token 时间差超过阈值处切断。

### 2. 滑动窗口与预加载机制 (Sliding Window Prefetch)
视频字幕通常有数千句，不能在播放开始瞬间全量并发翻译（易造成 API 额度耗尽、429 限流或长时间白屏）。
- **沉浸式策略**：
  - 维持当前播放时间戳 `t`；
  - 将 `[t - 5s, t + 45s]` 区间内的未翻译句子标记为**最高优先级（High Priority）**，立即并发批量送翻；
  - 空闲网络带宽时，分批预加载后续句子；
  - 无论用户如何快进（Seek），均优先调度当前播放点附近的字幕。

### 3. 多种双语显示模式的设计哲学
不同人群对双语字幕的诉求各异：
| 显示模式 | 适用人群 | 视觉层级 |
| :--- | :--- | :--- |
| **上译下原 (Target First)** | 绝大多数追求轻松观影的用户 | 译文字号更大、颜色更亮，原文字号偏小、颜色偏柔和。 |
| **上原下译 (Source First)** | 外语听力学习、对照跟读者 | 原文字号较大，方便视线第一时间对准原文。 |
| **仅译文 (Target Only)** | 仅需要当中文母语视频观看者 | 画面极其清爽，只占单行空间。 |
| **仅原文 (Source Only)** | 外语纯听力练习或对照阅读 | 规避机翻干扰，用于听力训练。 |

### 4. 极致的文本渲染与文字阴影 (Text Readability)
在复杂多变的视频画面背景下（如纯白背景雪地、阳光场景），普通白字或透明底色极易产生眩光不可读。
沉浸式翻译采用复合文字轮廓描边：
```css
text-shadow: 
  0 0 2px #000,
  0 0 4px #000,
  -1px -1px 0 #000,  
   1px -1px 0 #000,
  -1px  1px 0 #000,
   1px  1px 0 #000,
   0 2px 4px rgba(0,0,0,0.85);
```
此方案无论在暗色、亮色还是全透明背景下，字幕边缘均极其锐利。

### 5. 时间轴微调偏移 (Time Sync Offset)
由于自动语音识别或视频压制时可能存在声音与画面字幕的微小时间差（±100ms ~ 500ms），提供快捷的时间轴微调（`offsetMs`），能极大提升用户的临场体验。

## 四、 本项目对照与优化蓝图

结合沉浸式翻译的核心亮点，本项目重点强化以下关键能力：
1. **支持 4 种双语呈现模式**（上译下原、上原下译、仅译文、仅原文），快速面板支持即点即切；
2. **引入智能滑动窗口就近预加载引擎**（优先保证当前画面和后续 30s 字幕实时就绪）；
3. **强化文字阴影与描边渲染**，解决透明背景下的阅读痛点；
4. **增加时间戳微调（Sync Offset）功能**，支持 ±0.5s 同步矫正；
5. **全屏状态自适应放大**。
