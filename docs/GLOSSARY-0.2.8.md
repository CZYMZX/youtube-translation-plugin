# v0.2.8 术语库（VTuber / hololive）

日期：2026-11-04
目录：`E:\Antigravity\油管翻译插件_v0.2.8`（v0.2.7 存档不动）

## 一、功能

- **术语库入口**：设置面板「通用与翻译」标签页新增折叠卡片「术语库」（与 API 配置卡同一交互样式），徽章显示条目总数，可展开查看、搜索、按分类筛选。
- **翻译注入**：开启后，每批翻译只把**本批文本实际命中**的术语注入 system prompt（最多 40 条），强制模型采用统一译名、禁止括注原文；关闭则完全不注入。
- **缓存隔离**：术语库版本号参与翻译缓存键——术语更新后旧译文自动失效，不会出现“新旧译名混用”。

**来源原则**：`source` 字段为每条术语标注原始 URL，`sourceType` 区分 `official`（官网）/ `wiki`（维基）/ `community`（业界通用，如 歌枠/切り抜き/凸待ち/初見/同時接続/待機所/ホロメン）。UI 中悬停分类标签可见来源；未核实的中文译名一律不收录（如部分新成员无公认译名则跳过）。

**采集方式说明**：原计划使用 `browser-use` CLI 自动化采集，但该 CLI 未安装（`command not found`，Python 模块亦缺失），按 skill 规则不改用其它浏览器自动化替代，改为 WebFetch 直接抓取官方站与维基条目（来源可核验）。

## 三、代码结构

```
utils/glossary.ts        # 数据 + 匹配 + prompt 块生成（GLOSSARY_VERSION 参与缓存键）
utils/translator.ts      # buildSystemPrompt(settings, targetLang, texts) 注入命中术语
utils/db-cache.ts        # buildSentenceCacheKey 增加 glossaryTag 参数
types/index.ts           # glossaryEnabled?: boolean（默认 true）
utils/storage.ts         # 清洗：非 false 即启用
entrypoints/popup/*      # 折叠卡片 UI + 搜索/分类/开关
test/test-glossary.js    # 23 项断言
```

匹配规则：日文原词子串匹配，长度 ≥2；按词长降序取前 40 条，控制 prompt 体积（实测单批增量 <120 token）。
